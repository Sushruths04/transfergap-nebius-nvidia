Stage 5

Which stage failed, and what fixes it

Replace one stage at a time by simulator truth and see how much success comes back. That is the Transfer Gap Budget. NVIDIA Nemotron-3-Super then reads those numbers and picks one fix per round from a fixed menu; the choice is committed before the held-out trials.

Gap budget on the dev seeds (pp recovered)

Perception is the biggest item on both arms. Negative bars: replacing that stage by truth did not help.

Nemotron versus the deterministic rule

Video critic

Can Cosmos tell success from failure?

Cosmos-Reason2-2B watches simulator clips of this demo. Out of the box it calls everything a success. With the adapter trained earlier on other demos it catches most failures and raises no false alarms on the successes.

Reading the result

All 55 failures are in the no-correction clips, so the fixed-run clips (120, all successes) only test for false alarms. Simulator renders only, one demo, one person, one camera: not evidence for real-robot video.

Straight talk

What is not solved

The G1 does not reproduce the person's picking style. 0 of 30 grasps open loop; the closed-loop hybrid reaches 13 of 40 placements on generic blocks.
One clip, one person. The held-out seeds were reused from development, so the gains are paired comparisons, not a fresh test.
Perception and calibration errors are assumed, not measured. The budget would need a real robot or a calibrated camera model to be absolute.
Pose only works for a static camera with the person in view; internet clips were refused by the plausibility gate. Grasp and release frames were given by hand; the object is not detected.
Nemotron agreed with the rule at every step. It is in the loop, but this run does not show it beats the rule.
Where this goes

The next version of this system

These are plans, not results. None of it is built yet.

NEXT · DAYS

Live webcam, closed loop

The camera, pose, retargeting and robot already run at 17 to 21 fps from a recorded video; the next step is you in front of the lens, with end-to-end latency measured.

NEXT · DAYS

Ten demonstrators, one scoreboard: which people's styles transfer, which break, and why. Needs more clips and a measured scale per person.

SOON

Swap RTMW3D for GEM-X or Fast SAM 3D Body to handle moving cameras and internet video, with a bake-off protocol already in place.

SOON

Use the critic live to decide when to look again, instead of only scoring clips afterwards.

VISION
